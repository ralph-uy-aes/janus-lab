# Docs

One write-up per phase. Each is written *after* the phase's "done when" test passes.
Raw notes stay private; these are rewritten for a reader who wasn't there.

Suggested outline (matches the plan's post template):
1. The goal in one sentence
2. The design choice and why (and the alternative rejected)
3. What was done, with a diagram
4. How it was tested
5. What went wrong
6. What's next
